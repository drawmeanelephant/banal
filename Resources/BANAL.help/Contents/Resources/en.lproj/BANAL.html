BANAL Help

Write notes as files. Keep them where you can see them.

Write File your notes Find your way Read or publish Keyboard shortcuts Your files are the source of truth

Write

File → New Note (⌘N), then start typing. BANAL saves the note as a regular file on disk — Markdown, Textile, or Cooklang. File → New Textile and File → New Recipe create the other languages.

File your notes

Folders in the sidebar are real folders on disk. File → New Folder (⇧⌘N), or drag a note onto a folder to move it. Move to Trash (⌘⌫) sends the file to the Finder trash.

Find your way

Find Notes (⌘F) searches titles, bodies, tags, and recipe ingredients. Find in Note (⇧⌘F) searches the open note. Click a folder in the sidebar to narrow the list.

Read or publish

Every note has Edit and Read. Use View → Read Note (⌘]) for a quiet reading view — recipes show ingredients, cookware, and steps. Publishing is optional: mark notes Published and choose File → Publish Site (⇧⌘P). Writing works without Oliver, Boris, or Cloudflare.

Your files are the source of truth

Markdown, Textile, and Cooklang notes live in the folder you chose. Open them in Finder or any text editor — BANAL notices changes and updates the list.
