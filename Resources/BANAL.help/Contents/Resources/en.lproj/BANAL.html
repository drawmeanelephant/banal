BANAL Help

Write notes as files. Keep them where you can see them.

Write File your notes Find your way Read or publish Your files are the source of truth

Write

Choose File → New Note (⌘N), then start typing. BANAL keeps the source in the editor and saves the note as a regular file on disk.

File your notes

Folders in the sidebar are real folders in your notes folder. Use File → New Folder (⇧⌘N), or drag a note onto a folder. Move to Trash (⌘⌫) uses the Finder trash.

Find your way

Find notes with ⌘F. Find in the current note with ⇧⌘F. ⌘1, ⌘2, and ⌘3 focus the folders, note list, and editor.

Read or publish

Use View → Read Note for a quiet reading view. To publish, mark notes Published and choose File → Publish Site… (⇧⌘P). Publishing is optional; writing works without Oliver, Boris, or Cloudflare.

Your files are the source of truth

Markdown, Textile, and Cooklang notes stay in the folder you chose. You can open and edit them in Finder or another text editor, and BANAL will notice changes.
