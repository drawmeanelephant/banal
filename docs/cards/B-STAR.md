**Lane:** all chrome · **Status:** binding · Read [`../NORTH-STAR.md`](../NORTH-STAR.md)

This is not a research card. It is how you decide whether a pixel stays.

## Do

1. Default window: folders, list, page. Nothing else permanent.
2. First action is typing. No tour.
3. Search appears when asked (⌘F), not as a forever chrome tax.
4. Published is a menu/shortcut, not a form row.
5. Tags are not a sidebar place.
6. Copy is short. If you need a second sentence, the UI is wrong.
7. Density in the list. Air in the editor.

## Gate

Sit in the running app for five minutes. If you are explaining it, you failed.
