# Card B-X — Refuse

**Milestone:** always · **Lane:** policy · **Status:** binding

Not a build card. Read before every PR. Deletion is how the
window stays sexy.

## Never

| Temptation | Why it dies |
|------------|-------------|
| Graph / backlinks pane | Boris’s graph is a compile artifact. A pane makes us Solipsist. |
| Solipsist Compose | Explicitly forbidden. New editor, or none. |
| Pantry, meal plan, grocery aisles | Oliver does not cook. We do not become Paprika. |
| AI complete / chat with notes | Thesis failure test. |
| Daily notes ritual | A file named today’s date is allowed. A religion is not. |
| Plugin mall | No. |
| Electron / Tauri | No. |
| Webview as editor | Preview/read only, if ever. |
| Fourth Settings pane | You are hiding a product. |
| Onboarding carousel | Empty states are B-3. |
| Streaks, word-count karma | Anti-fun list in the thesis. |
| Themes named after cities | One pairing. System appearance. |
| Sync we operate | The folder is the sync. |
| Worker / R2 multi-tenant host | Not a notes feature. |

## Maybe later, still not a pane

- Whispered markup highlighting (not a theme)
- Prose preview for Markdown/Textile
- Save a scaled recipe copy
- Signed `.app` / sandbox

## The test

If you have to explain the change with “it’s like Obsidian
but…” or “it’s like Paprika but…”, do not land it.

If the default window gains a column, stop.

If dinner and a paragraph stop feeling like the same kind of
easy, stop.
